# Руководство хоста

Хост — тот, кто создал комнату (👑 на карточке). Если хост уходит, права переходят следующему игроку по времени входа.

## Пригласить друзей {#invite}

- **⧉ Скопировать ссылку** — отправьте в мессенджер.
- **QR** — наведите камеру телефона.
- Или продиктуйте **код комнаты** из 5 символов (без похожих 0/O и 1/I).

Играть можно в одной комнате или по созвону/стриму: у каждого свой экран и свой микрофон.

## Настройки комнаты {#settings}

| Настройка | Что делает |
|---|---|
| Раунды | 3, 5 или 7 |
| Режим | **Классика** — каждый озвучивает весь клип; **Командный дубляж** — клипы с 2+ ролями, игроки делятся на команды и роли; **Импровизация** — без текста, только тайминги |
| Рейтинг клипов | 0+, 12+ (по умолчанию) или 16+ |
| Выбор клипа | голосование игроков или выбирает хост |
| Анонимно | имена авторов дублей скрыты до итогов раунда |
| Без спешки | все таймеры ×3 (удобно для новичков и доступности) |
| Не пускать новых | во время игры новые участники не смогут войти |

Начать игру можно, когда в комнате минимум 2 игрока.

## Во время игры {#during}

- Кнопка **⏭** в верхней панели завершает текущую фазу досрочно (если кто-то задерживает всех).
- В лобби через меню **⋯** на карточке игрока можно **переименовать** или **выгнать** его. Выгнанный не сможет вернуться в эту комнату.
- В финале — **«Играть ещё»**: очки обнуляются, сыгранные клипы не повторяются.

## Командный дубляж {#roles}

Игроки делятся на команды, не больше, чем ролей в клипе, и минимум две команды. Внутри команды роли распределяются по очереди; если вы в команде один — озвучиваете все роли. Голосуют за команды, очки получают все участники команды.
