# Руководство автора клипов

Клип в DubRoom — это **пакет**: видео без диалогов, фоновая дорожка (музыка и эффекты) и разметка реплик. Подготовить его можно в **Clip Studio** (в браузере) или вручную в привычных программах и загрузить через CLI.

## Требования к клипу {#requirements}

- Длина **любая**: короткая сцена на 10–60 с, трейлер игры или вырезка из сериала на десятки минут (до 3 ч по умолчанию). Длинный клип в игре делится на **сцены** — см. [ниже](#scenes). 1–4 персонажа в сцене, хорошо видны лица и губы, мало наложенной речи.
- Разрешение исходника **≥ 480p**; форматы MP4/MOV/MKV (H.264, H.265, VP9, AV1).
- **Права обязательны:** собственное видео, CC0 / CC BY, public domain или письменное разрешение. Укажите источник и лицензию.
- Возрастной рейтинг: 0+, 12+ или 16+.

## Clip Studio по шагам {#studio}

1. **Импорт.** «+ Новый клип» → видео, по возможности фон без голосов (M&E) и отдельно голос. Заполните название, источник, лицензию, рейтинг. Загрузка идёт частями и продолжается после обрыва связи. Если браузер не умеет показывать ваш формат (например, HEVC с iPhone), Studio за минуту сделает превью.
2. **Обрезка.** Поставьте видео на нужный кадр и нажмите «[ Начало = кадр» / «Конец = кадр ]» (или клавиши <kbd>I</kbd>/<kbd>O</kbd>).
3. **Голос.** Загрузите фон и голос, если не сделали этого при импорте. Без отдельного фона в игре будут слышны оригинальные голоса — такой клип модератор, скорее всего, отклонит.
4. **Реплики.** Добавьте роли (имя и цвет). Для каждой реплики: <kbd>N</kbd> — новая с текущего момента, <kbd>I</kbd>/<kbd>O</kbd> — начало/конец, текст, подсказка интонации («уверенно», «шёпотом»). <kbd>Space</kbd> — пуск/пауза, <kbd>←</kbd>/<kbd>→</kbd> — ±1 кадр. Можно импортировать SRT.
5. **Сцены.** Для длинного клипа: «Авторазбивка» или <kbd>[</kbd> — разрезать в текущем моменте, <kbd>]</kbd> — склеить с соседней. Дайте сценам названия («Погоня», «Допрос»). Масштаб таймлайна — <kbd>+</kbd>/<kbd>−</kbd>.
6. **Проверка.** Справа — автоматические проверки. Посмотрите клип «как у игрока», «оригинал» и сделайте **тестовую запись**: совпал ли ваш голос с губами?
7. **Экспорт.** «Отправить на обработку» — сервер сделает видео в нескольких качествах, нормализует громкость фона, постер, превью и субтитры. Затем клип попадёт на **модерацию**: второй человек проверит права, рейтинг и качество и опубликует его.

Новую версию опубликованного клипа можно сделать из библиотеки («Новая версия»); старая версия остаётся для отката.

## Ручной путь (без Studio) {#manual}

### 1. Мастер

Экспортируйте клип: MP4, H.264, 1080p или 720p, постоянные 25/30 fps, звук 48 кГц стерео.

### 2. Отделите голос от фона

Лучше всего — исходная M&E-дорожка. Иначе нейросеть Demucs:

```bash
pip install demucs
demucs --two-stems=vocals -n htdemucs master.wav
# separated/htdemucs/master/no_vocals.wav — фон, vocals.wav — голос
```

Прослушайте `no_vocals.wav` в местах реплик. «Призраки» голоса приглушите в Audacity (Эффекты → Усиление −12 дБ на участке) или замените фоном из соседнего места.

### 3. Разметьте реплики в SRT

Каждая реплика начинается с метки роли, подсказка — в скобках в конце:

```
1
00:00:01,200 --> 00:00:03,900
[r1] Мы оба знаем, чья это миска. (уверенно)
```

Удобно в Subtitle Edit или Aegisub: откройте видео и `vocals.wav`, ставьте границы по волне с запасом ~100 мс.

### 4. Нормализуйте фон

```bash
ffmpeg -i no_vocals.wav -af loudnorm=I=-23:TP=-2:LRA=11 bed.wav
```

### 5. Соберите и отправьте пакет

```bash
dubroom-clip init ./my-clip --video master.mp4 --bed bed.wav --dialogue vocals.wav --title "Кот-переговорщик"
# заполните credit, license, ageRating, имена ролей в my-clip/manifest.json
dubroom-clip lines ./my-clip --from-srt dialogs.srt --role-map roles.json
dubroom-clip validate ./my-clip
dubroom-clip publish ./my-clip --api https://play.example.com --key $STUDIO_KEY
```

`roles.json` сопоставляет метки из SRT с ролями: `{"Кот": "r1", "Пёс": "r2"}`. Команда `dubroom-clip separate ./my-clip` запускает Demucs за вас. `dubroom-clip build ./my-clip` соберёт пакет локально — удобно проверить результат до отправки.

## Автоматически в Google Colab {#colab}

Блокнот [`tools/colab/DubRoom_Clip_Factory.ipynb`](../../tools/colab/DubRoom_Clip_Factory.ipynb) делает пакет почти без ручной работы — на бесплатном GPU Google Colab:

1. Откройте блокнот в Colab (кнопка «Open in Colab» вверху или «Файл → Загрузить блокнот»), включите GPU: «Среда выполнения → Сменить среду → T4 GPU».
2. В форме «Параметры клипа» вставьте ссылку на видео (YouTube, VK Видео, Rutube…) или выберите файл, при необходимости — обрезку, название, источник и лицензию.
3. «Среда выполнения → Выполнить все». Блокнот скачает видео, отделит голос от фона (Demucs), распознает реплики с таймингами (Whisper), разложит их по ролям по голосам, нарежет длинный клип на сцены по паузам и склейкам и проверит результат по правилам сервера.
4. Посмотрите таблицу реплик и превью «как у игрока». Ошибки распознавания правятся в `subtitles.srt` (метки ролей `[r1]`, `[r2]`, подсказка — в скобках в конце) или потом в Clip Studio.
5. Сохраните ZIP на Диск или сразу отправьте в Clip Studio: адрес Studio + ключ `STUDIO_KEY` (секрет Colab 🔑). Режим `draft` загружает черновик для доработки в редакторе, `submit` — отправляет на обработку и модерацию.

Пакетный режим (шаг 9) обрабатывает список ссылок подряд. Если Studio закрыта Cloudflare Access, администратор выдаёт service token — см. [руководство администратора](../admin/README.md).

Автоматика — черновик, а не финал: перед отправкой всегда проверьте роли и текст.

## Длинные клипы и сцены {#scenes}

Трейлер или фрагмент серии играется **по сценам**: в каждом раунде — одна сцена, следующая попадётся в другом раунде или другой игре. Хост может включить «Длинные клипы → целиком» — тогда клип играется от начала до конца, видео и голоса идут потоком (одна попытка, без репетиции, если клип длиннее 3 минут).

- Сцена — **от 5 с до 2 мин**, лучше 30–60 с, с законченным смыслом.
- Реплика не может пересекать границу сцены: Studio сама сдвигает разрез в конец реплики.
- Если сцены не размечены, у клипа длиннее 90 с они появятся автоматически — по паузам в диалоге, около 45 с каждая. Проверьте их на шаге «Сцены».
- Разрезы на чётных секундах обрабатываются быстрее (без перекодирования).
- Исходники длиннее 10 минут Studio не скачивает целиком: видео идёт потоком, волна строится на сервере — подождите «Готовим превью…».

## Автоматические проверки {#checks}

- длительность от 5 с (не больше лимита сервера, по умолчанию 3 ч), минимум одна реплика, реплики одной роли не пересекаются;
- сцены: 5 с…2 мин, не перекрываются, реплики не пересекают границы;
- заполнены название, рейтинг, источник, лицензия;
- исходник ≥ 480p, поддерживаемые форматы;
- громкость фона нормализуется до −23 LUFS;
- предупреждения: остаток голоса в фоне в местах реплик, чёрный экран дольше 2 с.

## Чек-лист автора {#checklist}

- [ ] Права и источник указаны
- [ ] Голос в фоне не слышен в местах реплик
- [ ] Реплики размечены, роли назначены
- [ ] Тестовая запись совпала с губами
- [ ] Возрастной рейтинг выставлен
