# Руководство автора клипов

Клип в DubRoom — это **пакет**: видео без диалогов, фоновая дорожка (музыка и эффекты) и разметка реплик. Подготовить его можно в **Clip Studio** (в браузере) или вручную в привычных программах и загрузить через CLI.

## Требования к клипу {#requirements}

- Длина **10–60 с** (допустимо 5–90), 1–4 персонажа, хорошо видны лица и губы, мало наложенной речи.
- Разрешение исходника **≥ 480p**; форматы MP4/MOV/MKV (H.264, H.265, VP9, AV1), до 2 ГБ.
- **Права обязательны:** собственное видео, CC0 / CC BY, public domain или письменное разрешение. Укажите источник и лицензию.
- Возрастной рейтинг: 0+, 12+ или 16+.

## Clip Studio по шагам {#studio}

1. **Импорт.** «+ Новый клип» → видео, по возможности фон без голосов (M&E) и отдельно голос. Заполните название, источник, лицензию, рейтинг. Загрузка идёт частями и продолжается после обрыва связи. Если браузер не умеет показывать ваш формат (например, HEVC с iPhone), Studio за минуту сделает превью.
2. **Обрезка.** Поставьте видео на нужный кадр и нажмите «[ Начало = кадр» / «Конец = кадр ]» (или клавиши <kbd>I</kbd>/<kbd>O</kbd>).
3. **Голос.** Загрузите фон и голос, если не сделали этого при импорте. Без отдельного фона в игре будут слышны оригинальные голоса — такой клип модератор, скорее всего, отклонит.
4. **Реплики.** Добавьте роли (имя и цвет). Для каждой реплики: <kbd>N</kbd> — новая с текущего момента, <kbd>I</kbd>/<kbd>O</kbd> — начало/конец, текст, подсказка интонации («уверенно», «шёпотом»). <kbd>Space</kbd> — пуск/пауза, <kbd>←</kbd>/<kbd>→</kbd> — ±1 кадр. Можно импортировать SRT.
5. **Проверка.** Справа — автоматические проверки. Посмотрите клип «как у игрока», «оригинал» и сделайте **тестовую запись**: совпал ли ваш голос с губами?
6. **Экспорт.** «Отправить на обработку» — сервер сделает видео в нескольких качествах, нормализует громкость фона, постер, превью и субтитры. Затем клип попадёт на **модерацию**: второй человек проверит права, рейтинг и качество и опубликует его.

Новую версию опубликованного клипа можно сделать из библиотеки («Новая версия»); старая версия остаётся для отката.

## Ручной путь (без Studio) {#manual}

### 1. Мастер

Экспортируйте клип: MP4, H.264, 1080p или 720p, постоянные 25/30 fps, звук 48 кГц стерео.

### 2. Отделите голос от фона

Лучше всего — исходная M&E-дорожка. Иначе нейросеть Demucs:

```bash
pip install demucs
demucs --two-stems=vocals -n htdemucs master.wav
# separated/htdemucs/master/no_vocals.wav — фон, vocals.wav — голос
```

Прослушайте `no_vocals.wav` в местах реплик. «Призраки» голоса приглушите в Audacity (Эффекты → Усиление −12 дБ на участке) или замените фоном из соседнего места.

### 3. Разметьте реплики в SRT

Каждая реплика начинается с метки роли, подсказка — в скобках в конце:

```
1
00:00:01,200 --> 00:00:03,900
[r1] Мы оба знаем, чья это миска. (уверенно)
```

Удобно в Subtitle Edit или Aegisub: откройте видео и `vocals.wav`, ставьте границы по волне с запасом ~100 мс.

### 4. Нормализуйте фон

```bash
ffmpeg -i no_vocals.wav -af loudnorm=I=-23:TP=-2:LRA=11 bed.wav
```

### 5. Соберите и отправьте пакет

```bash
dubroom-clip init ./my-clip --video master.mp4 --bed bed.wav --dialogue vocals.wav --title "Кот-переговорщик"
# заполните credit, license, ageRating, имена ролей в my-clip/manifest.json
dubroom-clip lines ./my-clip --from-srt dialogs.srt --role-map roles.json
dubroom-clip validate ./my-clip
dubroom-clip publish ./my-clip --api https://play.example.com --key $STUDIO_KEY
```

`roles.json` сопоставляет метки из SRT с ролями: `{"Кот": "r1", "Пёс": "r2"}`. Команда `dubroom-clip separate ./my-clip` запускает Demucs за вас. `dubroom-clip build ./my-clip` соберёт пакет локально — удобно проверить результат до отправки.

## Автоматические проверки {#checks}

- длительность 5–90 с, минимум одна реплика, реплики одной роли не пересекаются;
- заполнены название, рейтинг, источник, лицензия;
- исходник ≥ 480p, поддерживаемые форматы, не длиннее 10 минут;
- громкость фона нормализуется до −23 LUFS;
- предупреждения: остаток голоса в фоне в местах реплик, чёрный экран дольше 2 с.

## Чек-лист автора {#checklist}

- [ ] Права и источник указаны
- [ ] Голос в фоне не слышен в местах реплик
- [ ] Реплики размечены, роли назначены
- [ ] Тестовая запись совпала с губами
- [ ] Возрастной рейтинг выставлен
