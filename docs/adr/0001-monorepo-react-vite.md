# ADR-0001: Монорепозиторий pnpm, TypeScript, React + Vite
Статус: принято

Контекст: клиент, Studio, API, игровой сервер и воркер делят типы протокола, схему манифеста и правила игры (§6.2–6.3). Разные версии этих типов в разных репозиториях — главный источник рассинхронизации.

Решение: один pnpm-workspace. `packages/*` подключаются исходниками TypeScript (без отдельной сборки): Vite собирает фронтенд, `tools/build-node.mjs` (esbuild) инлайнит их в бандлы Node-сервисов. React 19 + Zustand для UI, Vitest для тестов, Playwright для E2E.

Последствия: + одна команда `pnpm check`, общие типы без публикации пакетов; − пакеты нельзя использовать вне монорепо без сборки.

Альтернативы: Svelte (меньше бандл, но меньше опыта в команде), Nx/Turborepo (избыточно для 11 пакетов).
