# ADR-0006: Подписанные тикеты и квитанции вместо presigned URL
Статус: принято

Контекст: §11.6 предлагает загружать дубли напрямую в S3 по presigned URL. На MVP хранилище — диск (ADR-0003).

Решение: игровой сервер в фазе записи выдаёт каждому участнику **тикет загрузки** (HMAC, комната + раунд + игрок, живёт до конца фазы + 5 мин). API принимает дубль только с тикетом, проверяет размер (≤ 2 МБ) и формат по сигнатуре файла, сохраняет под **случайным непрозрачным id** и возвращает **квитанцию** (HMAC: id + комната + раунд + игрок). Игровой сервер принимает `dubUploaded` только с валидной квитанцией.

Почему непрозрачный id: первая версия кодировала в id игрока, что раскрывало авторов в анонимном режиме через URL файла.

Последствия: + нельзя загрузить дубль в чужую комнату/раунд или выдать чужой файл за свой; ключи подписи ротируются с периодом двойной валидности (§22.8).
