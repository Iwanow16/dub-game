# ADR-0007: Синтетический стартовый набор клипов в git
Статус: принято

Контекст: игре нужны клипы с первого запуска (§17, этап 1: 5 клипов). Бинарные видео в git раздувают репозиторий, а у открытых фильмов свои условия атрибуции.

Решение: `content/starter-pack/*` хранит только манифест и рецепт `synth.json`. `dubroom-clip synth` генерирует FFmpeg-ом сцену: персонажи цвета роли, «рот» открывается ровно во время реплик, фоновая музыка. `seed-clips.sh` прогоняет их через обычный конвейер Studio API → воркер → публикация. Лицензия CC0.

Последствия: + игра работает сразу после установки, E2E-тесты детерминированы; − сцены простые — к публичному запуску (этап 4) нужны 50 настоящих клипов по контент-плану (приложение C).
