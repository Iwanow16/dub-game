# ADR-0005: Прогрессивный MP4 + VP9/WebM вместо HLS
Статус: принято

Контекст: клипы короткие (≤ 90 с), их нужно полностью загрузить до записи (§11.3). Часть браузеров (открытые сборки Chromium, Firefox на некоторых Linux) не декодирует H.264 — это выяснилось в E2E-тестах: вместо видео показывался постер.

Решение: воркер делает лестницу H.264 720/480/360p (faststart, GOP 2 с) **и** 480p VP9/WebM. Клиент выбирает ступень по `canPlayType`: H.264 предпочтительнее (аппаратное декодирование), VP9 — запасной вариант. Звук — отдельная дорожка `bed` (Opus + AAC). HLS не нужен; GOP 2 с оставляет возможность перейти на CMAF без перекодирования.

Для Studio воркер делает ещё и **прокси для редактирования** (VP9/Opus WebM) — исходники авторов (HEVC .mov с iPhone, MKV) браузер часто не показывает.

Последствия: + ~15 % больше места на клип; − ещё один проход кодирования (~2–4 с на 30-секундный клип).
