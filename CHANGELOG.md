## [0.2.2] — 2026-10-03

### Исправлено
- `harden.sh` мог оставить администратора без доступа по SSH. Теперь по умолчанию режим `classic` (порт 22 открыт с ограничением частоты, только ключи); `--ssh-mode access` закрывает порт только после подтверждения и никогда с `--yes` — раньше он был режимом по умолчанию и закрывал SSH при установке через `setup.sh`.
- Вход по паролю отключается, только если последний вход администратора был по ключу: ключ, который положил в `authorized_keys` хостинг, больше не считается доказательством. Иначе скрипт показывает отпечатки ключей и спрашивает.
- При ручном запуске изменения SSH и фаервола сами откатываются через 10 минут, если не подтвердить, что новый вход работает.
- Документация: как вернуть доступ через консоль хостинга.

## [0.2.1] — 2026-10-03

### Исправлено
- `start.sh` и другие скрипты падали на сервере с туннелем по токену: `.env: --no-autoupdate: command not found`. Файл `.env` теперь разбирается так же, как его читает Docker Compose, а не выполняется bash-ом.
- `setup.sh`, `tunnel.sh token` и `rotate-secrets.sh` принимают и целиком вставленную команду установки из панели Cloudflare — из неё берётся сам токен; явно неверное значение отклоняется с подсказкой.

## [0.2.0] — 2026-09-29

Клипы любой длины: трейлеры игр, вырезки из сериалов ([ADR-0009](docs/adr/0009-long-clips-scenes-and-streaming.md)).

### Что нового для игроков
- Длинный клип играется **по сценам**: в раунде — одна сцена со своими репликами и ролями; на карточке — «Сцена N из M» и длительность.
- Настройка комнаты «Длинные клипы → целиком»: клип от начала до конца, видео и голоса идут потоком без полной предзагрузки, просмотр остаётся синхронным.
- Для клипов длиннее 3 минут — одна попытка без репетиции; время фазы записи зависит от длины клипа.
- В стартовом наборе — 2,5-минутный трейлер и 7-минутный фрагмент «сериала».

### Для авторов
- Лимит 90 с снят: длина до 3 ч (настраивается).
- Clip Studio: шаг «Сцены» (авторазбивка, разрезать/склеить `[`/`]`, названия), масштабируемый таймлайн ×1…×64, потоковое превью и серверная волна для исходников длиннее 10 минут.
- Проверки сцен: 5 с…2 мин, без перекрытий, реплика не пересекает границу; автосцены для клипов длиннее 90 с.

### Для администраторов
- Новые параметры `.env`: `CLIP_MAX_MINUTES` (по умолчанию 180) и `DUB_MAX_MB` (64).
- Воркер режет пакеты сцен (копированием потока на сетке ключевых кадров 2 с), таймауты и пресеты кодирования зависят от длины.

### Технически
- `Playable` (клип или сцена) в каталоге, `pickCandidates` предпочитает разные клипы; лимит размера дубля в тикете растёт с длиной клипа.
- Воспроизведение потоком через `MediaElementAudioSourceNode` с подстройкой дрейфа по часам `AudioContext`.
- `scripts/dev.sh` останавливает процессы группами и проверяет, что порты свободны.

## [0.1.0] — 2026-09-28

Первый вертикальный срез (этап 1 плана) с частью этапов 2–3.

### Что нового для игроков
- Игра по ссылке без регистрации: имя, аватар-конструктор с 24 пресетами, комнаты по 5-символьному коду, ссылке или QR.
- До 6 игроков и зрители; режимы «Классика», «Командный дубляж» и «Импровизация»; 3/5/7 раундов, анонимное голосование, «без спешки».
- Запись дубля с репетицией, отсчётом, бегущими репликами, двумя попытками, прослушиванием, шестью эффектами голоса и подстройкой синхронизации ±200 мс.
- Калибровка задержки по хлопкам, подсказки для микрофона в каждом браузере.
- Синхронный просмотр всех дублей, реакции, голосование, очки, приз зрительских симпатий, финал с «лучшим дублем игры».
- Переподключение в течение 60 с без потери места и очков.
- Режим «Попробовать одному», справка `/help`, RU/EN.
- Пять стартовых клипов.
- Кнопка «Пожаловаться» на клип или игрока.

### Для авторов
- Clip Studio: загрузка до 2 ГБ частями с докачкой, обрезка, разметка реплик по волне с горячими клавишами, импорт SRT, проверки, предпросмотр и тестовая запись, отправка на обработку, модерация, версии и откат.
- CLI `dubroom-clip`: init, synth, separate (Demucs), lines, validate, build, publish.

### Для администраторов
- Установка на чистый сервер скриптами, публикация через Cloudflare Tunnel без открытых портов.
- Скрипты эксплуатации: start/stop/status/logs/update (с откатом)/backup/restore/tunnel/harden/security-check/rotate-secrets/uninstall.
- Изолированные контейнеры (non-root, read-only, cap_drop ALL), воркер медиа без сети.

### Технически
- Монорепо pnpm: web, studio, api, game-server, media-worker, help; пакеты shared, clip-format, audio, ui, db.
- Отличия от плана зафиксированы в ADR: SQLite и файловое хранилище вместо PostgreSQL/Redis/MinIO (ADR-0003), MediaRecorder (ADR-0004), VP9-запасной вариант к H.264 (ADR-0005).
